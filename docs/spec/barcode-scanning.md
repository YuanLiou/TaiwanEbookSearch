# 條碼掃描

## 產品目的

`SCAN-001` 條碼掃描的目的，是讓使用者掃描實體書背面的條碼，再用掃描值搜尋可能對應的電子書。

## 掃描流程

`SCAN-002` 只有裝置具備相機功能時，搜尋列才顯示相機入口。

`SCAN-003` 掃描功能必須先取得 Android 相機權限。未授權時顯示權限說明與授權入口；永久拒絕或無法直接請求時，可引導使用者前往系統設定。相機權限只供掃描流程使用。

`SCAN-004` 掃描 Library 目前只設定辨識 EAN-13。App 不額外驗證條碼是否為 ISBN、不檢查 ISBN checksum，也不轉換 ISBN-10。

`SCAN-005` 辨識到 EAN-13 後，App 顯示該值並震動提示。使用者點擊顯示的掃描結果後，才將數值帶回主畫面並直接執行搜尋。

`SCAN-006` 掃描結果使用與手動輸入相同的搜尋、歷史紀錄、防重複請求及錯誤規則。

## 相機互動

`SCAN-007` 相機預覽允許點按對焦，並在辨識到條碼時標示辨識範圍。相機啟動失敗時必須提供可觀察的錯誤提示。

## 主要實作入口

目前主要入口是 `CameraPreviewActivity`、`BarcodeScanner`、`CameraPreviewScreen` 與 `CameraUseCase`。條碼格式由 ML Kit 掃描器設定限制。
