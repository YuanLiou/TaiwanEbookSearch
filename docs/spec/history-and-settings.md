# 搜尋紀錄與設定

## 搜尋紀錄

`HISTORY-001` 搜尋紀錄保存在裝置本機，跨 App 重啟保留，不提供 App 帳號或跨裝置同步。

`HISTORY-002` 完全相同的搜尋字串合併為同一筆，累加搜尋次數並更新時間。大小寫、前後空白或其他字元不同時視為不同紀錄。

`HISTORY-003` 歷史紀錄依最近搜尋時間由新到舊顯示。App 保存累計搜尋次數，但目前不在 UI 顯示。

`HISTORY-004` 搜尋欄取得焦點且至少有一筆紀錄時，顯示歷史紀錄。點擊紀錄會直接重新搜尋該字串。

`HISTORY-005` 使用者可以刪除單筆紀錄，刪除前必須確認；也可以從設定清除所有紀錄，清除前必須確認，完成後顯示成功結果。

`HISTORY-006` 一般搜尋與快照的保存時機分別遵循 `SEARCH-016` 與 `SNAPSHOT-004`。

## 外觀

`PREF-001` App 預設使用明亮主題，且預設不跟隨系統。

`PREF-002` 使用者可選明亮或深色主題，也可啟用跟隨系統。啟用跟隨系統後，手動主題選項必須停用。

## 結果排序

`PREF-003` 「依價格排序」預設開啟。它只控制各書店區段內的結果，不影響「最佳結果」。完整排序規則見 `SEARCH-007` 至 `SEARCH-009`。

## 商品頁開啟方式

`PREF-004` 「使用瀏覽器分頁」預設開啟。它只影響手機單欄模式，大畫面分欄模式固定使用內建 WebView。

## 書店來源與順序

`PREF-005` 使用者可以拖曳調整書店順序，也可以取消勾選以停用來源。

`PREF-006` 系統必須至少保留一家啟用來源。只剩一家時不得再停用該來源。

`PREF-007` 保存後的啟用清單與順序必須同時影響下一次 API 請求、最佳結果來源集合、書店區段顯示順序及服務狀態頁的開關狀態。

## 本機持久化

`PREF-008` 搜尋紀錄、書店啟用與順序、價格排序、主題、Custom Tab 偏好及評分邀請狀態都保存在本機並跨 App 重啟保留。

`PREF-009` 使用者清除 App 資料或解除安裝後，App 本身不保證復原。Android 系統備份可能搬移資料，但不屬於 App 自行提供的同步功能。

## 主要實作入口

搜尋紀錄目前使用 SQLDelight；書店順序與評分狀態使用 Preferences DataStore；畫面偏好使用 Android SharedPreferences。主要入口是 `SearchRecordRepositoryImpl`、`PreferenceSettingsViewModel`、`BookStoreReorderViewModel`、`BookRepositoryImpl` 與 `UserPreferenceManagerImpl`。儲存技術可替換，但上述資料語意必須維持。
